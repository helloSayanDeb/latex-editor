# TeXStudio Local 2.0.2

11 October 2026. A local privacy and image-assistance update.

## Changes

- Paste screenshots into TeX Sage with Ctrl/Cmd + V, or upload one PNG/JPEG/WebP reference image. PDFs and other attachments are unsupported. Images are resized, re-encoded to remove metadata and sent only with the current request.
- Local model menus show Text, Vision or Unverified badges. Upload/paste requires verified vision support. LM Studio and Ollama metadata determine local capabilities; unknown models retain text chat.
- Ask with No source is the default. Source sharing is explicit and previewable; recent chat is optional. Conversations are separated by provider/endpoint and kept in memory.
- Saved-key encryption now uses random salt/IV and stronger password derivation. Legacy keys remain readable; unlock and save settings to upgrade them. Gemini credentials use a header and cloud errors redact keys.
- Local launchers bind to loopback and supply private session tokens. APIs validate local host/origin and session access. Compiler jobs have bounded input, concurrency, execution time and output, with restricted primitives and a reduced environment.
- Generated external references require confirmation, including protection against middle-click/context-menu bypass. AI has no filesystem or terminal tools.
- Sharing controls collapse into one summary row. Chat and find/replace share clear custom checkmarks. Settings inputs match the provider dropdown; the message box is about 1.5 lines high.
- Production npm startup uses Next.js's standalone server. Desktop smoke tests wait for automatic welcome compilation and clean up failed test servers.

## Installation

Download the Windows x64 installer or macOS Intel/Apple Silicon DMG from this release. The runtime is bundled. TeX, Git and local AI servers/models remain separate installations. Installers are unsigned; macOS is not notarized. Editing works without TeX, but PDF compilation needs MiKTeX/TeX Live/MacTeX and the document's packages/fonts.

## Verification and limits

Production build, privacy/image contracts and the 25-check live feature audit pass on Windows. LM Studio image transcription was tested with `google/gemma-4-e2b`. Windows packaging and installer flow are checked locally; release CI checks packaged startup on Windows and both macOS architectures. CI does not establish complete macOS DMG installation or native TeX compatibility on a user's Mac.

Cloud and Ollama adapters have mocked text/image request tests, not verification of every live account/model. Native compilation, PDF navigation, Markdown and inline-edit regression checks remain available in the repository.

This is a trusted personal local workstation. The safeguards are **not an OS-level TeX sandbox**, do not defeat malware running as your user, and do not guarantee model obedience against prompt injection. Advanced direct Lua/file-I/O/primitive use can be rejected. Only compile trusted projects. Public hosting is unsupported. Known feature limitations remain documented in [the feature audit](../FEATURE_AUDIT.md).
